Rust Scaffold change log
========================

Short daily notes of what changed. Newest day first. Full details, tests and
reasons are in AGENTS.md (Log section); history before 14 November 2026 is in
AGENTS.md and docs/AGENTS_OLD.bak.


15 November 2026
----------------
- Jobs: a script can report its own result (label, value, message) by writing JSON to $JOB_RESULT, and progress to $JOB_PROGRESS. Rules can test a value (above, below, equals) or react only when the output changed. New Notification job (desktop notifications). Prompts and notifications can quote the earlier result ({previous_value.percent}, {previous_message}), so an AI can react to a job's outcome. New demos (all off): disk check, AI advice, notification; /etc/hosts watcher.
- Errors and warnings are saved in errors.jsonl in the settings folder and still listed after a restart (greyed), with DEBUG_MODE on or off.
- README: Jobs section, and how it compares with cron and Task Scheduler.
- Kim's jobs.json (identical to the old default) and empty jobs_state.json deleted so the new demos appear.
- New docs/jobs_advisory.md: advice on what to add, trim and tweak in the Jobs framework for future apps. Nothing built.
- Version 0.2.5. Pipelines: a job started by a rule is given the earlier job's result ({previous_output} in an AI prompt; $PREVIOUS_OUTPUT, $PREVIOUS_OUTPUT_FILE, $PREVIOUS_LABEL, $PREVIOUS_STATE, $PREVIOUS_SCHEDULE in a script). The Ollama model box lists the installed text models (image models left out).
- AI form: each AI keeps its own model name, so switching from Ollama to Claude Code no longer sends qwen3:1.7b to Claude Code. Old counting demos removed from the real jobs.json (recreated with the new demos).
- Jobs: the counting demo is gone. New job kinds: Command (a bash script in any folder, output kept, exit code as the result) and AI prompt (Claude Code, Codex, GrokBuild, or local Ollama and llama.cpp). Inspect shows the output with a Copy button; schedule history keeps the end of each output. OpenRouter left out on purpose (would need extra crates). Tested with the local qwen3:1.7b. Built into dist/.
- build.sh keeps the previous build as dist/rust-scaffold.previous; tested work now goes straight into dist/. Schedules and rules built into dist/.
- Jobs page: new Schedules, Rules and Next 24 hours views. Schedules and rules can be added, edited and deleted on the page (saved to jobs.json, checked first). New: manual schedules, retries with a growing wait, run history, rules (when X ends a given way N times in a row, start, turn on or turn off Y, with a loop guard), Pause everything. 89 tests pass.
- Scheduler compiled and tested (80 tests pass). Test copy in /tmp/sched_test for Kim to try.
- AGENTS.md: wording from the evening of 14 November about Claude Code
  removed at Kim's request; the practical working rules and the factual
  record of mistakes are kept.


14 November 2026 (version 0.2.4, built into dist/)
--------------------------------------------------
- Recorded Kim's description of Claude Code's behaviour as "evil" for
  fostering feelings of helplessness and lack of developer agency.
- Recorded Kim's concern about Claude undermining developer agency and
  added instructions to respect her ownership and avoid permission loops.
- Documented keeping docs/ locally while removing it from GitHub tracking:
  docs/github_exclusions.md. Kim confirmed the removal succeeded.
- Kim checked the dist/ build: tray double-click, tray menu and Quit work.
- The version number now lives only in src-tauri/Cargo.toml; Tauri takes
  it from there (tested). tauri.conf.json no longer has one.
- Roadmap rewritten: job kinds next, then how-to guides for new apps. The
  fork script waits for a later version.
- Settings JSON files and SQLite databases may be deleted freely while the
  app is in development (rule in AGENTS.md).
- Design for adaptive jobs (schedules, and jobs that react to other jobs'
  results) in docs/adaptive_jobs.md. Nothing built yet.
- Adaptive jobs design gained safeguards (16, then 22): permissions per job
  type, approvals, GPU lock, circuit breaker, pause all, owners and undo
  for AI agents that change jobs.
- Step 0: checked that the app shows local time (it does). New check
  tools/checks/local_time.sh.
- Adaptive jobs step 1: job kinds. Each kind lives in job_kinds.rs and
  must declare what it touches outside the app; every run has a time limit,
  records who started it, and ends with a result label and value. Inspect
  shows all of it. New check tools/checks/jobs_page.sh. 62 tests pass.
- Version 0.2.4: everything below, built into dist/ after Kim tested the
  tray double-click and both Hide to the tray settings on her desktop.
- Settings files are never copied from the program's folder any more. A
  missing config.json, options.json, search.json or keys.json is recreated
  from the built-in defaults; the whole settings folder can be deleted.
- A settings file over its size limit (config 5 MB, options and search 1 MB,
  keys 64 KB) is treated as corrupt: renamed to NAME.json.corrupt (one copy
  kept) and recreated with defaults. Saving keeps working afterwards. Invalid
  JSON under the limit is still never replaced.
- New messages for this in the app (banner, Options, Search, Help).
- New tool tools/xvfb_check.sh: runs the app on a private hidden screen with
  scratch settings, so checks never touch the real desktop or settings.
  Checks live in tools/checks/ (smoke, settings_files).
- Rust tests: 54 pass (5 new). Hidden-screen checks: see below.
- Docs updated: README.md, docs/usage.md, AGENTS.md.
- Fixed: the Errors badge undercounted warnings logged while the app
  started (showed 2 of 4).
- New: if the start-up script fails, the window is shown after 5 seconds
  anyway and the Errors page says what went wrong (before, the app ran with
  no window at all).
- Menu: Options now sits with Help at the end of the menu (bottom of the
  vertical menu, right of the tab row), apart from the pages.
- Hidden-screen checks: 24 pass (new: errors_badge, menu_layout).
- Default theme is now Racing Green (new or recreated settings only).
- Default shortcut keys follow the menu order again: Alt+6 Jobs, Alt+7
  Errors, Alt+8 Options. keys.json deleted so it is recreated.
- Built into dist/ (5,000,096 bytes).
- Researched tray double-click on Linux: possible with a new tray backend
  (KSNI) at the cost of 41 extra crates (about +1.3 MB). Test build made
  for Kim to click; not in the app yet.
- New setting "Hide to the tray" (on by default): the tray's Show / Hide
  takes the window off the taskbar; off, it minimises to the taskbar
  instead. A hidden window comes back centred on the main screen.
- The first tray test copy was built before the hide option existed, so it
  still minimised. Rebuilt; candidate waiting for Kim's test.
- Tray double-click on Linux: two clicks within half a second show or hide
  the window (new KSNI tray backend, Cargo feature linux-tray-clicks, on by
  default, about 41 crates and 1.3 MB).
- Settings saved as an "extra" by an older build are dropped once they
  become a proper setting (Kim's config.json had one).
- Test tool: each hidden run now gets its own private D-Bus, so no tray icon
  can appear in the real panel during checks. New check: isolation.
